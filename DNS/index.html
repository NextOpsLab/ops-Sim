IP Address Types

Private IP Addresses

  • Range: 192.168.x.x
  • Range: 10.x.x.x
  • Range: 172.16.x.x - 172.31.x.x
  • Usage: Internal network only
  • Not routable: Cannot access internet directly
  • Example: Your laptop in home network

Public IP Addresses

  • Unique globally: No duplicates worldwide
  • Routable: Can communicate over internet
  • Assigned by ISPs: Internet Service Providers
  • Example: 101.23.7.8 (Facebook server)
  • Cost: Usually paid/leased

Key Point: Your router has both!

Private IP (192.168.1.1) for internal network + Public IP (from ISP) for internet

The Problem: Remembering IP Addresses

Without DNS, you'd need to remember:

https://101.23.7.8 (Facebook) https://142.250.191.14 (Google) https://157.240.11.35 (Instagram) https://31.13.79.246 (WhatsApp)

With DNS, you can use:

https://www.facebook.com https://www.google.com https://www.instagram.com https://web.whatsapp.com

DNS (Domain Name System)

The "Phone Book" of the Internet
Translates human-readable names → IP addresses

DNS Resolution Process

When you type: www.facebook.com

1
Local Cache Check
Browser checks: "Do I already know this IP?"
Result: Not found (or expired TTL: 10s)
2
OS DNS Server
Operating System checks its DNS cache
Result: Not found (TTL expired)
3
Root DNS Server
"I don't know facebook.com, but ask .com servers"
Returns: .com TLD server addresses
4
Top Level Domain (.com)
"I don't handle facebook.com directly, ask Facebook's DNS"
Returns: Facebook's authoritative DNS server
5
Authoritative DNS (facebook.com)
Facebook's DNS (e.g., Hostinger) responds
Returns: www.facebook.com → 101.23.7.8 (A record)

Component Breakdown:

  • www → Host/Device (web server)
  • facebook → Domain Name (company)
  • .com → Top Level Domain (commercial)
  • . → Root Directory (hidden)

DNS Record Types:

  • A Record: IPv4 address mapping
  • AAAA Record: IPv6 address mapping
  • CNAME Record: Alias/canonical name
  • MX Record: Mail exchange
  • NS Record: Name server
Example DNS Record: www.facebook.com. A 101.23.7.8 (IPv4 address)

Practical Example: nslookup

Command: nslookup www.facebook.com

Server: Unknown Address: 10.245.242.31 Non-authoritative answer: Name: star-mini.c10r.facebook.com Addresses: 2a03:2880:f16b:183:face:b00c:0:25de 31.13.64.35 Aliases: www.facebook.com

Understanding the Output:

  • Server: Your DNS resolver
  • Address: DNS server IP (10.245.242.31)
  • Non-authoritative: Cached response
  • Name: Actual server name
  • Addresses: IPv6 & IPv4
  • Aliases: www.facebook.com is an alias

Key Insights:

  • Facebook uses multiple IP addresses
  • Load balancing across servers
  • IPv6 support (future internet)
  • CDN (Content Delivery Network)
  • Geographic distribution
