What Is Linux?

🐧
  • Linux = Kernel + GNU Tools
  • Open Source: Source code is freely available
  • Free: No licensing fees
  • Community-developed: Millions of contributors worldwide
  • Unix-like: Based on Unix principles and design

Fun Fact: Created by Linus Torvalds in 1991 when he was just 21 years old!

Linux vs Unix

🐧 Linux

Origin: Created by Linus Torvalds (1991)

Licensing: GPL (Free & Open)

Source Code: Open Source

Cost: Free

🔧 Unix

Origin: Bell Labs (1970s)

Licensing: Proprietary

Source Code: Closed Source

Cost: Commercial

Linux is Unix-compatible but completely rewritten!

  • BIOS/UEFI: Hardware initialization
  • Bootloader: GRUB loads the kernel
  • Kernel: Core system starts
  • systemd: Modern init system
  • Services: Network, graphics, etc.
  • Login: Ready for user!

Running a Command in Linux

What happens when you type a command?

Shell Parse
Fork Process
Exec Program
Kernel Execute
Output
Exit Status
user@linux:~$ ls -la
1. Shell parses "ls -la"
2. Fork creates new process
3. Exec replaces with 'ls' program
4. Kernel executes the program
5. Output shows files
6. Exit with status code (0 = success)
